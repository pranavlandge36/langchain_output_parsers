# LangChain Output Parsers Practice

## 📌 Overview

This project focuses on learning and applying **output parsers in LangChain** to handle structured responses from LLMs, especially when models do not natively support structured output.

## 🚀 What I Learned

* Implemented different types of output parsers:

  * **String Output Parser**
  * **JSON Output Parser**
  * **Structured Output Parser**
  * **Pydantic Output Parser**
* Understood how to extract reliable, machine-readable data from LLM responses
* Learned how to handle models that do not support native structured output using parsing techniques
* Explored validation and schema enforcement using Pydantic

## 🛠️ Tech Stack

* Python
* LangChain
* Pydantic

## 📂 Project Files

* `with_structured_output_typeddict.py` → Structured output using TypedDict
* `with_structured_output_pydantic.py` → Structured output using Pydantic
* `with_structured_output_json.py` → JSON-based structured output
* Additional scripts demonstrating output parser usage

## 🎯 Use Case

Applied output parsers to generate **detailed, structured information about characters from Valhalla Marvel**, enabling consistent and rich responses from LLMs.

## 💡 Key Takeaway

Output parsers are essential when working with LLMs that lack native structured output support, allowing developers to enforce format consistency and reliability.
